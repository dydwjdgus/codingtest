# 🧩 코딩테스트 문제 회고

## 🧩 문제

* **문제 제목** : 문자열 반복해서 출력하기
* **문제 레벨** : Lv.0
* **문제 유형** : 문자열
* **문제 제공** : 프로그래머스
* **문제 링크** :

---

## 🧩 문제 핵심

* 문자열과 반복 횟수 `n`을 입력받는다.
* 입력받은 반복 횟수는 문자열이므로 정수로 변환한다.
* 문자열 곱셈을 사용해 문자열을 `n`번 반복해서 출력한다.

## 🧠 내 풀이 핵심

```python
str, n = input().strip().split(' ')
n = int(n)
print(str*n)
```

* **핵심 로직** : `split()`으로 문자열과 반복 횟수를 나누고, `n`을 정수로 바꾼 뒤 문자열에 `n`을 곱해 반복 출력했다.
* **사용한 개념** : `input()`, `strip()`, `split()`, 형 변환 `int()`, 문자열 곱셈

## 💡 배운 점

* 파이썬에서는 문자열에 정수를 곱하면 같은 문자열을 반복해서 만들 수 있다.
* `input().split()`으로 한 줄에 들어온 여러 값을 나눠 받을 수 있다.

## ⚠️ 오답 포인트

* `split()`으로 받은 `n`은 문자열이기 때문에 반드시 `int()`로 변환해야 한다.
* 변수명을 `str`로 쓰면 파이썬 내장 함수 `str()`과 이름이 겹치므로 다른 이름을 쓰는 것이 좋다.

## 🧩 복잡도

* 시간복잡도 : O(len(str) * n)
* 공간복잡도 : O(len(str) * n)

## 🔍 트리거

* 같은 문자열을 여러 번 반복해야 하는 문제
* 입력값 중 숫자가 문자열로 들어와 형 변환이 필요한 문제
