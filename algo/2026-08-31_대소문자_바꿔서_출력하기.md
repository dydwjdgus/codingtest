# 🧩 코딩테스트 문제 회고

## 🧩 문제

* **문제 제목** : 대소문자 바꿔서 출력하기
* **문제 레벨** : Lv.0
* **문제 유형** : 문자열
* **문제 제공** : 프로그래머스
* **문제 링크** :

---

## 🧩 문제 핵심

* 입력받은 문자열을 한 글자씩 확인한다.
* 대문자는 소문자로, 소문자는 대문자로 바꾼다.
* 변환한 문자를 줄바꿈 없이 이어서 출력한다.

## 🧠 내 풀이 핵심

```python
str = list(input())
#1.문자를 받는다.
#2.리스트로 나누기
#3.리스트 원소를 하나씩 k에 넣기
#4.k가 대문자인지 판별하기
#5.대문자라면 lower()로 반환하기

for k in str:
    if k.isupper():
        print(k.lower(), end='')
    else:
        print(k.upper(), end='')
```

* **핵심 로직** : 문자열을 리스트로 만든 뒤 반복문으로 각 문자를 확인하고, `isupper()`로 대문자인지 판별해서 `lower()` 또는 `upper()`를 적용했다.
* **사용한 개념** : `input()`, `list()`, `for` 반복문, 조건문, 문자열 메서드 `isupper()`, `lower()`, `upper()`, `print(end='')`

## 💡 배운 점

* 문자열도 반복문으로 한 글자씩 순회할 수 있다.
* `print()`는 기본적으로 줄바꿈을 하므로, 이어서 출력하려면 `end=''`를 사용해야 한다.

## ⚠️ 오답 포인트

* 변수명을 `str`로 쓰면 파이썬 내장 함수 `str()`과 이름이 겹치므로 다른 이름을 쓰는 것이 좋다.
* 문자열은 바로 반복할 수 있기 때문에 `list(input())`으로 꼭 변환하지 않아도 된다.

## 🧩 복잡도

* 공간복잡도 : O(n)
